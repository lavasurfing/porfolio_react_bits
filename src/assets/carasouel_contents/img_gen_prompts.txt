PORTFOLIO IMAGE GENERATION PROMPTS
==================================
Use these prompts to generate carousel / project cover art for the portfolio.
Each image should feel abstract and intelligent — suggest the theme without literal UI screenshots,
logos, or text labels.

GLOBAL STYLE (append to every prompt)
------------------------------------
dark editorial tech aesthetic, near-black background (#0a0a0a to #111827), cinematic lighting,
soft volumetric glow, minimal composition, premium portfolio quality, subtle grain,
no text, no logos, no watermarks, no faces, no stock-photo clichés, 16:9 aspect ratio,
high contrast with restrained accent color, clean negative space on one side for overlay text

SITE COLOR PALETTE (pick one accent per image)
----------------------------------------------
- Project 1: deep violet (#8b5cf6) + teal (#0f766e)
- Project 2: amber (#f59e0b) + warm charcoal
- Project 3: emerald (#22c55e) + slate black
- Project 4: sky cyan (#38bdf8) + midnight blue
- Project 5: burnt orange (#f97316) + dark graphite
- Project 6: soft lavender (#a78bfa) + indigo (#312e81)

PROJECT 1 — Agentic AI Infrastructure Harness
Suggested filename: project-01-agentic-harness.webp
Accent: violet + teal
================================================================================

MAIN PROMPT:
An abstract illustration of a secure closed-loop network: three luminous nodes orbiting inside
a translucent circular boundary, connected by thin encrypted light trails that never exit the ring.
A central orchestration core pulses quietly, with faint telemetry arcs tracing motion between nodes.
Feels like governed intelligence — controlled, monitored, and contained. Minimal, futuristic,
architectural rather than robotic.

NEGATIVE PROMPT:
robots, humanoid AI, chat bubbles, server racks, padlocks, cartoon shields, bright white background,
busy clutter, readable text, brand logos

PROJECT 2 — Hugging Face Agentic Workflow Automation
Suggested filename: project-02-workflow-automation.webp
Accent: amber + warm charcoal
================================================================================

Suggested filename: project-05-api-performance.webp
Accent: burnt orange + dark graphite
================================================================================

MAIN PROMPT:
A single luminous data highway cutting through darkness — first calm and narrow, then expanding

NEGATIVE PROMPT:
